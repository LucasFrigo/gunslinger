# Feature Roadmap & Key Concepts: VR Gunslinger Game

Ordered cheapest → costliest for an agent to implement, given what already exists. Cost is the context a turn has to hold, how many live systems a wrong edit breaks, and how many sessions a miss takes. A stronger model plans the upper tiers; a cheaper model implements once that plan is settled. An item that names a dependency stays after it.

**Agent pick** on each item names the model and effort for the plan and the build. Tiers, cheapest first: Haiku 4.5 → Sonnet 5.5 → Opus 5.5 → Fable 5.1. Effort runs `low` → `medium` → `high` → `xhigh` → `max`. Raise effort before you raise the tier. Go up a tier when the work is physics or feel the agent cannot see, or when a wrong edit reaches combat resolve or netcode.

**Living status of what already ships:** `[docs/FEATURES.md](docs/FEATURES.md)` · **How systems work:** `[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)` · **Bugs:** `[docs/BUGS.md](docs/BUGS.md)` · **Pre-release TODOs:** `[docs/RELEASE_TODOS.md](docs/RELEASE_TODOS.md)` · **SFX checklist:** `[docs/SOUND.md](docs/SOUND.md)` · **Shader code:** `[docs/SHADERS.md](docs/SHADERS.md)` · **Design / lore:** `[docs/design/README.md](docs/design/README.md)` · **Versions:** `[CHANGELOG.md](CHANGELOG.md)` / `[VERSION](VERSION)`

When an item below lands (or is clearly underway), update `docs/FEATURES.md`. When it is **done**, move the bullet to **Completed** at the bottom (do not leave strikethrough items in the active lists).

## 1. Low — small context

A cheaper model. One named file, or a catalog entry that already plays. Do not explore the repo.

1. **Shorter bullet trails:** Trails linger too long after the slug is gone. Drop `FADE_TIME` in `weapons/bullet_trail.gd` (currently 1.6s) so the ribbon disappears faster; optional debug knob. **Agent pick:** Haiku 4.5 (one constant).
2. **Replace placeholder SFX:** Combat cues play today via `PlaceholderAudio` except `duel_end.wav`. Check boxes in `[docs/SOUND.md](docs/SOUND.md)` as real files land in `assets/audio/`. Gunshot first. The cost is sourcing the audio, not code. **Agent pick:** Haiku 4.5 to wire each file once it exists.
3. **Barrel smoke:** Visible smoke coming out of the barrel after a shot. A short stub already plays (`VfxCatalog` `&"muzzle_smoke"` from `ImpactFeedback.shot_fired` / `assets/vfx/muzzle_smoke.tscn`); this is a lingering plume that reads as gunsmoke, not a 0.45s puff. One scene, but the look only shows in a screenshot or playtest, so expect a few tuning rounds. **Agent pick:** Sonnet 5.5 `medium`.
4. **Muzzle flash shader:** A shot shows a star at the muzzle. Today `WeaponBase._muzzle_flash()` (`weapons/weapon_base.gd`) only spawns a light. Add a billboarded quad with `weapons/muzzle_flash.gdshader`, a random `seed` per shot, and `life` tweened 1 → 0 over the light's 0.08 s. Draw the same quad in `ImpactFeedback._spawn_draw_warmup` so the first shot does not hitch. Same in VR, flat, AI, and MP (local cosmetic, no net). Code is in `[docs/SHADERS.md](docs/SHADERS.md)` §1. **Agent pick:** Sonnet 5.5 `low`.
5. **Banded light:** One shared two-step `light()` in `assets/shaders/toon_light.gdshaderinc`, included by `characters/body_skin.gdshader` and `characters/body_cavity.gdshader` so the wound is lit like the skin around it. It applies everywhere: scenario surfaces take the same include through the world surface shader (Moderate), and until that lands the world keeps smooth light. `[docs/SHADERS.md](docs/SHADERS.md)` §2. Run `chunks` and `ragdoll`. **Agent pick:** Sonnet 5.5 `low`.
6. **Skin edge light + hit flash:** `characters/body_skin.gdshader` gains an edge light on the silhouette, so a duelist reads against the fog at range, and a `flash` uniform that blinks the body white on a hit. `DummyBody` tweens `flash` from 1 to 0 over about 0.1 s where the body takes a hit; `edge_light` follows the scenario sun color from `TimeOfDay`. Hands keep the solid material and get neither. `[docs/SHADERS.md](docs/SHADERS.md)` §3. After banded light. **Agent pick:** Sonnet 5.5 `medium`.
7. **Bullet trail shader:** The ribbon gets a white-hot core, a soft edge, and a tail that thins out (`weapons/bullet_trail.gdshader`). `_rebuild_ribbon` in `weapons/bullet_trail.gd` writes UVs, `make_material` returns the `ShaderMaterial`, and the fade sets `fade`. The warmup ribbon in `autoload/impact_feedback.gd` gets UVs too. Raise `WIDTH` to about 0.035 so the soft edge does not read thinner. `FADE_TIME` belongs to **Shorter bullet trails** above. `[docs/SHADERS.md](docs/SHADERS.md)` §4. **Agent pick:** Sonnet 5.5 `medium`.
8. **Dithered smoke and dust:** `assets/vfx/muzzle_smoke.tscn` and `assets/vfx/world_dust.tscn` draw a quad with `assets/vfx/puff.gdshader` in place of the sphere: a lumpy puff that erodes with age through an ordered dither, in flat and VR alike. Chips, shards, and coins stay meshes. `VfxCatalog.spawn_for_compile` already warms it. The dither may sparkle in a headset; that is accepted for now and gets a look on the Quest. **Barrel smoke** above builds its plume on this shader if it lands second. `[docs/SHADERS.md](docs/SHADERS.md)` §6. **Agent pick:** Sonnet 5.5 `medium`.



## 2. Moderate — one focused session

A mid-tier coding model. The spec is already tight, or another actor already does the thing. Name the files. A stronger model does not earn its keep here.

1. **Wind bed + gusts:** Always-on outdoor wind, mixed per arena, plus occasional visual gusts that fire a gust SFX at the same moment. Bed can start from `ScenarioResource.ambience` (`scenario_base.gd`) — unused today. Gusts are a new `VfxCatalog` cue (dust/tumbleweed/cloth) paired with an `AudioCatalog` `&"wind_gust"` one-shot. Per map: quiet/still Main Street, drier Canyon, more height/air on Train Rooftop; Saloon stays interior (no outdoor bed). Cosmetic only (local, no net). Foley notes in `[docs/SOUND.md](docs/SOUND.md)`. `scenario_base.gd` already plays `ambience` when it is set; no scenario `.tres` sets one yet. **Agent pick:** Sonnet 5.5 `medium`.
2. **Sky shader:** `scenarios/sky_western.gdshader` replaces `ProceduralSkyMaterial` on the four outdoor scenarios. The gradient stays smooth and matches today's, so the fog still meets the sky ground; it adds a small sun disc with a halo and cel clouds from a seamless `NoiseTexture2D`, with a random `cloud_offset` per load and the cloud tint tied to the sun color. `TimeOfDay.apply` (`scenarios/time_of_day.gd`) sets shader parameters in place of the material properties, and the two `ProceduralSkyMaterial` casts in `dev/autotest.gd` follow. Carry each scene's curve over (Canyon `ground_curve` 0.12; Main Street, practice hub, Train Rooftop `sky_curve` 0.08). Saloon has no sky. The host already sends the time; the cloud offset is local. `[docs/SHADERS.md](docs/SHADERS.md)` §5. Run `load`, then scrub with F3. **Agent pick:** Sonnet 5.5 `high`.
3. **Ink outline:** An inverted-hull line (`characters/body_outline.gdshader`) as `material_overlay` on every body: NPCs, the remote avatar, the local body, and the local hands. The first-person body passes the skin's `clip_radius` so the neck cavity stays clear. Add the overlay to the probe in `BodyChunks.spawn_for_compile`. Check a holed body from several angles (the hull's inside can show through a cut the cavity pass does not cover) and the hands at arm's length in a headset; a mesh with split normals cracks the hull. Gibs and the dropped gun stay unlined. `[docs/SHADERS.md](docs/SHADERS.md)` §7. Run `chunks` and `ragdoll`. **Agent pick:** Sonnet 5.5 `high`.
4. **Screen overlay (iris + hurt vignette):** One quad per camera with `ui/screen_overlay.gdshader`, drawn over each eye with no screen read. The iris wipe replaces the black fade (`XRToolsFade`, used by `autoload/kill_cam.gd`) and the hurt vignette replaces `Hud.flash_red`, in flat and VR. Cameras: flat rig, VR rig, kill cam, death cam. Hide the node while the iris is open and `hurt` is 0; give it a large `extra_cull_margin` and a render priority under the UI. The shader has only been drawn on a flat camera, so the per-eye center and the comfort of a closing iris at kill-cam speed need a headset. `[docs/SHADERS.md](docs/SHADERS.md)` §10. Run `duel`. **Agent pick:** Sonnet 5.5 `high`; split it (vignette first, iris second) to keep each session small.
5. **World surface shader:** `assets/shaders/world_surface.gdshader` on every static scenario surface: the banded light, a grain lookup on flat-color ground and walls, and wind sway on plants, signs, and cloth. The swap happens at import: an import script on the scenario GLBs copies each material's color and texture into a `ShaderMaterial`, so the editor shows the real look. Skip a material that uses vertex colors, a normal map, or transparency; check what the GLBs carry first. The Train Rooftop belt (`scenarios/train_rooftop/scenery_belt.gd`) needs `grain_local` and no sway on its cacti. The sway can take its strength from **Wind bed + gusts** if that lands first. Same look in flat and VR. `[docs/SHADERS.md](docs/SHADERS.md)` §8. After banded light. Run `load`, then walk each scenario; measure frame time on the Quest. **Agent pick:** Opus 5.5 `medium` to plan the import script; Sonnet 5.5 `high` to apply it per scenario.
6. **Duel title cards:** Before the standoff, a Tekken-style intro isolates each duelist in turn. A fixed 3D camera points at them in the live arena, in whatever pose they are already holding; flat and VR both take that camera. A shared multilayer 2D card slams in from the side and holds about 2 seconds — one western template for every fighter, big letters are the name only. NPCs use `AIArchetype.display_name`. Humans use a display name in Settings; the Steam persona name overrides it while online. Order: in SP the NPC first, then the player; in 1v1 the host, then the joiner. Later 3+ modes cycle every combatant. You can walk, draw, and spin the revolver; fire stays locked. Fire or a button skips to the standoff, and in MP either peer skips both. A whoosh plays as the layers hit, plus a short sting per card. Plays on a new matchup in free duel, gauntlet, and 1v1; a rematch of that same duel skips it. Practice hub has no intro. The existing standoff → bell → draw still follows. The writeup is the plan; the cost is the shared camera, the card, and the skip RPC. This is the largest item in this tier: a new pre-standoff state in `gauntlet/duel_manager.gd`, a Settings name, the Steam persona, an MP skip RPC, rematch detection, and a fire lock. The VR camera can follow the spectator `XRCamera3D` swap that `autoload/kill_cam.gd` already does. **Agent pick:** Opus 5.5 `high` for one session. Sonnet 5.5 `high` is enough if you split it (SP card + camera first, MP skip second).



## 3. Very high — several sessions

The plan, and the part that is expensive to undo, stay on a stronger model. A mid-tier model can do the follow-through once a template exists.

1. **Mod Support:** Provide community modding capabilities (custom gun skins, custom maps, sound packs, and duel scenarios). Plan the loading boundary before any loader; a wrong API is costly to unwind. The plan also has to settle Quest (sideloaded content, store rules), whether mods may ship GDScript, and what the MP version check does with modded clients. **Agent pick:** plan on Fable 5.1 `high` (or Opus 5.5 `max`). Build each loader on Sonnet 5.5 `high` once the boundary is fixed.
2. **Campaign Mode:** Develop a narrative-driven or level-based single-player story mode. Highest session count here. The framework stays on a stronger model; a chapter is mid-tier work only after a template exists. **Agent pick:** plan the framework (progression, save, chapter format) on Opus 5.5 `xhigh`. Write chapters on Sonnet 5.5 `medium` once a template chapter exists. Story and lore can draw on `docs/design/`.



## Ideas

Not ready to build. These stay parked until you ask to mature one into a numbered section above. Add an item here only when asked. This list is not sorted by agent cost.

- **Airborne fire / mystic trick shots:** Optional tech/mystic branch: allow firing while the revolver is tossed and spinning, so you can go for mid-air trick shots. Today fire/reload require `held` (`weapons/weapon_base.gd`). Gate behind a flag so the grounded western default stays.
- **Shootable hat:** The hat is its own volume, separate from the head. A brim hit that misses the skull deals no damage and knocks the hat off along the shot as a rigid body, with a cloth thump. A ray that meets the head is still a headshot (`combat/combat_rules.gd`), and the hat comes off with that hit. The loose hat can be grabbed and seated back on the head (flat look + F, VR off-hand grip), then shot off again. It stays as it was through the death cam. The next standoff puts it on again. Every character that wears one — none do today; the live body is the hatless mannequin (`dummy.glb`). Blocked on the gunslinger outfit being worn in a duel. In 1v1 the host resolves the knockoff and the reseat so both peers agree.
- **More off-hand props:** Extra radial wedges beyond the cigarette, coin, ace, and bottle — badge, etc. Each needs a mesh vendored next to `assets/models/props/msc_cigarette.glb` and an entry in `PropController.ITEMS`; the wheel, attach, and stow plumbing already exist. Props are local-only today: remote avatars show nothing in the off hand, so MP pose sync (a flag plus the equipped id) is the other half. Cigarette polish that is still open: an ember emission / tiny light on the tip, and a readability pass on the thrown cig (real 8.4 cm scale is nearly invisible in flight — see `cig_spin_axis`).
- **More enemy NPCs:** Expand the roster beyond Drunk / Sheriff / Ghost. New opponents are new `ai/archetypes/*.tres` (`AIArchetype` — reaction, accuracy, draw, reload, move style). Wire them into the free-duel pick and gauntlet ladder rungs. Distinct silhouettes/meshes can follow once the gunslinger model is on AI. First design: [Half-head](docs/design/characters/half-head.md).
- **Train Map Concept:** A duel scene featuring a moving train passing between opponents. Players must either wait for the train to clear or attempt risky shots through open train cars. Train Rooftop already scrolls desert and horizon past a stopped train; this item is the train that crosses the lane.
- **Oil-field train:** A variant of the Train Map Concept. The same train crosses the lane, this time through open desert, with oil pumps (pumpjacks) scattered along both sides of the track. On the horizon, oil bursts burn as distant flame columns — a `VfxCatalog` cue, cosmetic only (local, no gameplay). Depends on the crossing train.
- **Severing (dismemberment):** A killing hit severs the whole head, an arm, or a leg and the piece rides the ragdoll (`characters/body_ragdoll.gd`). Scrapped for now in favor of hit chunks, which only knock a small patch out of the mesh. It would need pre-cut boolean meshes and stumps, keyed off the existing hitboxes. Cosmetic only; `combat/combat_rules.gd` stays as is.
- **Horseback duel stage:** Both duelists fight mounted. Each horse’s speed varies randomly, so relative motion (and the shot window) changes from duel to duel. New arena/scenario; riding locomotion + aim-on-the-move on top of the existing standoff.
- **Ranking & Leaderboard System:** Implement competitive online matchmaking, player ratings, and global/regional leaderboards on **Steam / desktop**. Not on the Meta Store SKU (LAN-only MP).
