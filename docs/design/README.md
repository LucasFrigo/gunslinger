# Design bible

Fiction and art direction for characters, arenas, set pieces, and story. Not a ship checklist — gameplay truth lives in [`FEATURES.md`](../FEATURES.md) and [`../Roadmap.md`](../../Roadmap.md). Do not treat anything here as implemented until it has a path in code.

## Layout

| Folder | Use |
|---|---|
| [`characters/`](characters/) | NPC and player-facing designs (look, voice, combat read, story role) |
| `scenarios/` | Arena / set-piece / encounter briefs (create when the first one lands) |
| `story/` | World, campaign beats, tone (create when the first one lands) |

One markdown file per subject. Kebab-case names (`half-head.md`). Put concept art or refs next to the file (`half-head.png`, etc.).

## Status on each page

Use the same vocabulary as FEATURES: `done` | `partial` | `planned` | `blocked`. Design-only pages stay `planned` until an archetype, mesh, or scene exists.
